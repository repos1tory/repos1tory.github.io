Add the repository once in Sileo or Zebra, then search for a package. These packages require an arm64 jailbreak environment; dependencies are listed in each package. After installing nodejs + wrangler-ios you can authenticate with wrangler login --device and deploy with wrangler deploy.

Packages are served directly from this repository. Updates appear after the package index is refreshed.
