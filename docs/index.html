tweaks

  • RateBar 0.2.1 — one signed number and an estimated time beside the battery percentage: net charge/drain power in watts, plus time to full or empty. download .deb
  • Psychosis 0.4.28-1 — system-wide touch and key injection plus accessibility automation for agent control, on device and remote. download .deb
  • HomeManager 0.2.0-13+debug — select multiple apps in jiggle mode and delete or move them. download .deb

apps

  • itop 1.1.0 — a high-refresh native system monitor drawn entirely in terminal glyphs: per-core CPU with history graphs, memory and jetsam pressure, disk, battery, and a live sortable process table with an htop-style key bar. iPhone and iPad layouts. download .deb

tools

  • CLM 1.0.0 — command line messaging: send iMessage (preferred) or SMS from the shell, routed through the Messages app. installs the clm command plus the sender. works on wi-fi-only ipads. download .deb

ports

  • cloudflared 2026.10.3-1 — Cloudflare Tunnel client running natively on jailbroken iOS: quick tunnels and HTTPS from the device, no companion server. download .deb
  • Node.js 22.19.0-1 — upstream Node.js 22 with full JIT and WebAssembly, bundled npm and npx. download .deb
  • Wrangler 4.151.0-1 — the Cloudflare Workers CLI (esbuild-wasm). deploy Workers straight from the device. download .deb
  • OpenCode Server 2.0.28-0ios39 — OpenCode agent server with iOS launchd watchdog and network relay support, bundled web app and native home-screen app. download .deb
