repos1tory

a minimal repository for jailbroken iOS

add this url to Sileo or Zebra:

https://repos1tory.github.io/

packages

  • Node.js 22.19.0-1 — upstream Node.js 22 with full JIT and WebAssembly, bundled npm and npx. download .deb
  • Wrangler 4.151.0-1 — the Cloudflare Workers CLI (esbuild-wasm). deploy Workers straight from the device. download .deb
  • OpenCode Server 2.0.28-0ios12 — OpenCode agent server with a bundled web app and native home-screen app. download .deb
  • MDControl 0.3.0 — local SpringBoard automation commands for taps, swipes, app launches, and accessibility snapshots. download .deb
  • MultiDelete 0.1.12-1+debug — select and remove multiple removable Home Screen apps and web apps in one confirmed action. download .deb

all packages target iphoneos-arm64 and require a rootless jailbreak. dependencies are listed per package — install Node.js before Wrangler.

packages are served directly from this repository; updates appear after the package index is refreshed.
