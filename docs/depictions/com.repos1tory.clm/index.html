CLM

command line message

Send iMessage (preferred) or SMS from the command line on a jailbroken device. Built for Wi-Fi-only iPads: the message is handed to the Messages app, which relays it over Wi-Fi (iMessage) or through iPhone Text Message Forwarding (SMS).

usage

clm "On my way" +15555555555
clm -s "Landline test" +15555555555
  • -s / --sms — force SMS instead of iMessage
  • recipient can be a phone number (with country code), an Apple ID, or an email
